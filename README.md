# Práctica: de la interfaz de VS Code a la consola de Git

En esta práctica trabajarás con la página web incluida en el repositorio para
comprender qué ocurre detrás del panel **Control de código fuente** de VS Code.

## Material

- [Guía para estudiantes](PRACTICA_GIT_CONSOLA.md)
- [Guía docente](GUIA_DOCENTE.md)

La práctica cubre el modelo de Git, inspección del repositorio, staging,
restauración de cambios, commits, historial, `reset` y navegación con
`checkout` en estado *detached HEAD*.

> La actividad está diseñada para ejecutarse en una rama de práctica. Los
> comandos que descartan trabajo se realizan únicamente después de crear
> puntos de recuperación.
